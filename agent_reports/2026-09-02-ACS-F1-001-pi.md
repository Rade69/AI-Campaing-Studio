## Implementation summary

### `domain/common/ids.py` (extended, `new_id()` untouched)

Added 10 typed ID aliases as `typing.NewType` (runtime-transparent `str`,
type-checker-distinct): `ProjectId`, `BrandId`, `BrandSnapshotId`, `FactId`,
`CampaignId`, `CampaignPlanId`, `CampaignItemId`, `PostId`, `RevisionId`,
`VisualSystemId`.

### `domain/common/errors.py` (extended)

Added `ErrorCode` values `INVALID_STATE_TRANSITION`, `INVARIANT_VIOLATION`,
`ENTITY_NOT_FOUND`, and three subclasses of the existing `DomainError`:
`InvalidStateTransition`, `InvariantViolation`, `EntityNotFound` — each with
`default_code`, following the existing `AppError` pattern (no `__init__`
override; `technical_context` stays out of `args`).

### `domain/brand/`

- `value_objects.py`: frozen `BrandVoice`, `Audience`, `ServiceDefinition`,
  `Restriction`, `VisualIdentity`. All collection fields are
  `tuple[str, ...]`, and a `__post_init__` coerces any `list` input to
  `tuple` so frozen models never hold a mutable collection (ACS-P0-004/005
  lesson).
- `entities.py`: frozen `Brand` and frozen `BrandSnapshot`. `BrandSnapshot`
  is immutable; collection fields (`audiences`, `services`, `restrictions`,
  `approved_fact_ids`) are coerced to `tuple` in `__post_init__`.

### `domain/facts/`

- `enums.py`: `FactStatus` (`APPROVED`, `SUPERSEDED`, `SOFT_DELETED`; no
  `PROPOSED` in Slice 1).
- `entities.py`: frozen `SourceReference` and frozen immutable `ApprovedFact`.
- `policies.py`: `is_fact_usable` (APPROVED only), `assert_fact_usable`
  (raises `InvariantViolation`), and `create_next_fact_version` which returns
  a new `ApprovedFact` with `version + 1` and `status=APPROVED` and never
  mutates the previous fact.

## Design decisions (documented for review)

1. **`Restriction` is minimal (`description: str` only).** The Faza 1 plan
   lists `Restriction` in §10 without any field spec. I did not invent a
   schema — the A4 fixture boundary schema will refine it.
2. **`BrandSnapshot.language/locale/script` are plain `str`.** This keeps the
   domain layer free of the `localization` package (which is in
   `forbidden_paths` for this task). Callers map them to the existing
   `ContentLanguageFamily`/`Script` enum values at the boundary.
3. **ID aliases use `NewType`** (not a plain `str` alias) so mypy can reject
   mixing e.g. `BrandId` and `FactId`. Runtime behaviour is identical to
   `str`; `new_id()` still returns plain `str`.
4. **`create_next_fact_version` returns only the new fact and does NOT mark
   the previous version `SUPERSEDED`.** The contract allows either choice;
   marking the previous version requires constructing a separate immutable
   snapshot, which a single-object return cannot express — so that stays the
   caller/persistence layer's responsibility. Documented in the docstring.
5. **Test file naming:** `test_entities.py` would collide between
   `brand/` and `facts/` under pytest's rootdir import mode (no `__init__.py`
   in test dirs), so they are named `test_brand_entities.py` /
   `test_fact_entities.py`.
