`PerformanceSource` (CSV_IMPORT/MANUAL/API — metrika ULAZI). Namjerno odvojeni:

### `metrics.py`

- `CanonicalMetricSet` — 9 platform-neutralnih metrika, SVE `None` default
  (reach, impressions, engagements, clicks, conversions, spend, revenue,
  video_views, watch_time_seconds). Validacija vrijednosti NIJE ovdje
  (P1.5-G5 posao).
- `MetricPeriod` — `start`/`end` value object; `__post_init__` odbija
  `end < start` (strogo `<`, pa `end == start` je validan zero-length period).

### `entities.py` — tri frozen dataclass-a

- `DistributionInstance` (Faza 0.7 §3) — pun identity + target +
  `distribution_source` + opcioni `external_account_id`/`external_content_id`/
  `published_at`.
- `PerformanceSnapshot` (Faza 0.7 §5) — vezan za `distribution_instance_id`
  (NE direktno ContentPiece), `period`, `observed_at`, `source`, `metrics`,
  opcioni `source_batch_id`, `raw_metrics: dict = field(default_factory=dict)`.
- `PerformanceImportBatch` (Faza 0.7 §13) — `row_count`/`matched_count`/
  `unmatched_count` (provjerljivost), `mapping_version`, opciona
  `source_file_name`/`platform_code`/`raw_source_snapshot_ref`.
