## Implementation summary + dokumentovane odluke

1. **`url_safety_policy` je čista, I/O-free politika sa injektabilnim DNS
   resolverom.** `validate_url` radi: scheme allow-list, userinfo reject,
   port allow-list, literal-IP parse + `validate_ip`, a za hostname IDNA →
   `dns_resolver(host)` i zahtijeva da SVAKI rezultat bude `is_global`.
   `dns_resolver` je `Callable[[str], tuple[str, ...]]`, default
   `system_dns_resolver` (getaddrinfo, strip IPv6 zone), a testovi injektuju
   fake → matrica ne dira stvarni DNS.
2. **Literalna IP obfuskacija (§6.2) je eksplicitno pokrivena bez DNS-a**:
   decimal (`2130706433`), hex (`0x7f000001`), octal (`0177.0.0.1`),
   hex-u-dotted (`0x7f.0.0.1`), IPv4-mapped IPv6 (`::ffff:127.0.0.1`),
   plus klasične 1–4-part inet_aton forme. IPv6 ide preko `ipaddress`.
3. **Routabilnost je `ip.is_global`**, ne `not is_private` (strože: hvata i
   loopback/link-local/reserved/broadcast/multicast/CGNAT).
4. **`http_fetcher`**: `requests` + `SafeHttpAdapter(HTTPAdapter)` koji
   re-validira `request.url` kroz politiku neposredno pre `super().send()`
   (na granici konekcije — defense-in-depth iza `fetch`-ove provjere).
   Redirect-i su MANUALNI (`allow_redirects=False`), svaki hop re-validiran;
   `Content-Length` se provjerava PRIJE buffering-a, plus streaming chunk
   limit (5 MiB) kao zaštita ako header laže; retry sa exponential backoff
   (max 3, samo transport greške; SSRF reject ide prije socketa).
5. **RFC 9309 fallback**: 4xx → allow (unavailable/nema robots), 429/5xx/
   network-error → disallow (unreachable), cache TTL 24h.
6. **`crawl_budget`**: `sleeper`/`clock` injektabilni → politeness timing test
   je deterministički i trenutan (bez stvarnog `sleep`).
7. **`domain_discovery`** poziva `url_safety_policy` na SVAKI kandidat
   (start, sitemap `<loc>`, `<a href>`) PRE dodavanja; budget limit po domeni;
   dedup posle normalizacije.
8. **`url_normalizer`**: lowercase scheme/host, IDNA→Punycode, default-port
   strip, RFC 3986 percent-encoding normalizacija (uppercase hex + decode
   samo UNRESERVED, `%2F` ostaje encoded), dot-segment collapse, query sort,
   fragment strip. Deterministički (isti ulaz → isti izlaz).

## Transparentna ograničenja / napomene

1. **DNS pinning (anti-TOCTOU) NIJE u v1.** `SafeHttpAdapter.send` validira
   `request.url` (uklj. DNS rezoluciju → odbija hostname koji rezolvuje na
   non-global IP) neposredno pre urllib3 konekcije, ali ne pin-uje sam IP u
   `socket.create_connection`. Teoretski uski TOCTOU prozor između
   `validate_url` DNS-a i urllib3 `getaddrinfo`. Thread-safe pinning preko
   `socket.getaddrinfo` monkeypatch-a je odbačen kao thread-unsafe (crawl je
   `ThreadPoolExecutor`), a `get_connection` IP-swap razbija HTTPS SNI.
   Test matrica (uklj. `localtest.me`/`nip.io`) je zadovoljena. Ako review
   traži pinning, to je follow-up fix.
2. **GitNexus `detect_changes`**: indeks je građen na glavnom klonu
   (`H:\AI Campaing Studio`) i stale je za worktree; za untracked fajlove
   prije commit-a vraća `No changes detected`. Scope je zato dokazan ručnim
   `git diff --name-only` gore (ekvivalent, precizniji za ovaj slučaj).
3. **Sitemap index rekurzija** (`<sitemapindex>`) nije implementirana —
   kontrakt traži `sitemap.xml` `<url><loc>`; prijaviti ako G6 traži index.
4. `domain_discovery` koristi `crawl_budget.can_crawl` (limit); politeness
   `wait_politeness` je namijenjen S2-G6 pipeline-u (modul je spreman/testiran).
