## Implementirane odluke

1. **Checkpoint POSLIJE faze** + `token.raise_if_cancelled()` prije upisa
   checkpointa i na svakoj iteraciji FETCH/EXTRACT/BUILD_FACTS petlje.
   Cancel usred faze → ta faza se ne broji (honest cancellation).
2. **G-WI-RECOVER**: `recover_expired_leases(run_id)` se poziva na početku
   `execute()` PRIJE FETCH petlje.
3. **Deterministički ID-jevi** (idempotencija/upsert): snapshot
   `run:<sha256(run_id:url)>`, chunk `<snapshot>:c<N>`, candidate
   `cand:<chunk_id>`, target `run:<sha256(run_id:url)>`, checkpoint
   `run:<sha256(run_id:phase)>`. Re-fetch istog URL-a → isti snapshot id →
   upsert, bez duplikata.
4. **FETCH retry**: transport greška → lokalni `_attempts` brojač; ispod
   threshold (default 3) → `PENDING` (requeue u istom run-u), na threshold →
   `FAILED`. SSRF (`FetchResult.error` sa `"unsafe:"`) → `SKIPPED_UNSAFE`
   terminal, BEZ retry-a, BEZ snapshot-a.
5. **CLASSIFY spojen u DISCOVER** (page_type_hint pri `register_crawl_targets`,
   jer G2 nema odvojen "update classify") — checkpoint za obje faze se ipak
   upisuje.
6. **RENDER no-op** (S2-G8 Playwright ne postoji) — checkpoint se upisuje.
7. **EXTRACT**: HTML → `content_extractor` → `boilerplate_filter` → podela na
   paragrafe (`\n\n`) → `deduplicator` → `SourceChunk`. Dokument (PDF/DOCX/XLSX
   po ekstenziji) → raw bytes u `NamedTemporaryFile` → injektovani G9
   extractor → gotovi `SourceChunk`-ovi.
8. **BUILD_FACTS**: deterministički 1:1 chunk→`FactCandidate` (status
   `PROPOSED`, `snapshot_id`+`chunk_id`). NULA LLM poziva (unit test grep
   dokaz: nema `AIRequest`/`TextGenerationPort`/`ai_provider`/`openai`).
