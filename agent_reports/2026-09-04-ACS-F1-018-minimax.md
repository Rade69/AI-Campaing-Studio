### Messages API shape (1.3.0 — RELEVANTAN)

```python
client.messages.create(
    *,
    max_tokens: int,                          # OBAVEZAN
    messages: Iterable[MessageParam],         # SAMO user/assistant
    model: ModelParam,
    system: Union[str, Iterable[TextBlockParam]] | Omit,  # TOP-LEVEL
    output_config: OutputConfigParam | Omit,  # NOVO: JSON-schema enforcement (1.0+)
    temperature: float | Omit,
    # ...
)
```

### OutputConfigParam shape (1.3.0)

```python
class OutputConfigParam(TypedDict, total=False):
    # nije total=True jer sva polja nisu required; specifikacija kaže
    format: JSONOutputFormatParam  # the actual schema-defining field

class JSONOutputFormatParam(TypedDict):
    schema: Required[Dict[str, object]]
    type: Required[Literal['json_schema']]
```

Dakle poziv izgleda:

```python
output_config={
    "format": {
        "type": "json_schema",
        "schema": request.json_schema,
    }
}
```

**Verifikovano u 1.3.0:** `inspect.signature(...).parameters["output_config"].annotation == "OutputConfigParam | Omit"`. Pydantic modeli postoje na putanji `anthropic.types.output_config_param.{OutputConfigParam, JSONOutputFormatParam}`. Server-side enforcement — model NE MOŽE vratiti tekst koji nije validan JSON prema šemi.

### Response shape (nepromijenjen od 0.105.2)

```python
class Message(BaseModel):
    id: str
    type: Literal["message"]
    role: Literal["assistant"]
    model: str | Literal[...]
    content: List[TextBlock | ...]      # LISTA BLOKOVA — za plain text: 1×TextBlock
    stop_reason: Literal['end_turn', 'max_tokens', 'stop_sequence', 'tool_use', 'pause_turn', 'refusal']
    stop_sequence: str | None
    usage: Usage
```

**BF-1 lekcija (prvobitna):** `stop_reason` na `Message` objektu, NE na `TextBlock`/`Choice`. `input_tokens`/`output_tokens` na `usage`. Test fixture-i koriste **stvarne pydantic klase** iz `anthropic` paketa.

### Error hijerarhija (1.3.0 MRO provjeren)

```
AnthropicError              (root, apstraktna)
└── APIError
    ├── APIStatusError      (4xx/5xx)
    │   ├── RateLimitError              (429)
    │   ├── AuthenticationError         (401)
    │   ├── BadRequestError             (400)
    │   ├── PermissionDeniedError       (403)
    │   ├── NotFoundError               (404)
    │   ├── ConflictError               (409)

    │   └── InternalServerError         (500+)
    └── APIConnectionError

```

**Retry semantika (ista kao i prije):** `RateLimitError`/`APIConnectionError`/`APITimeoutError` retry; ostali immediate `InfrastructureError`. Sve greške mapirane preko `_map_error()` — nikad sirov `AnthropicError`.

### Model discovery (1.3.0 — RELEVANTAN)

`client.models.list()` stabilan, vraća paginated `SyncPage[ModelInfo]`. `ModelInfo` ima: `id`, `type="model"`, `display_name`, `created_at`, `capabilities`, `max_input_tokens`, `max_tokens`. Adapter drainuje cijelu stranicu (discover je non-hot path).

### Structured output — ODLUKA IZ FIX RUNDE

`anthropic 1.0+` IMA `output_config` parametar na `messages.create` sa `format: {type: "json_schema", schema: ...}`. **Server-side enforcement** — funkcionalno ekvivalentno OpenAI-jevom `response_format=json_schema`.

**Prethodna runda (REJECTED):** prompt-based JSON direktiva u system_text. Problem: model može ignorisati instrukciju (DeepSeek je u ACS-F1-017 vratio 7 stavki umjesto traženih 3 bez enforced sheme).

**Fix runda (ova):** `output_config={"format": {"type": "json_schema", "schema": request.json_schema}}` na `messages.create`. `_compose_system_text` helper je UKLONJEN — `request.system_text` prolazi kroz adapter NEMODIFIKOVAN. Defanzivni code-fence strip u `_parse_structured` je ZADRŽAN kao sigurnosna mreža (za stare SDK/pre-1.0 modele koji ponekad echo-uju `\`\`\`json` fence).
