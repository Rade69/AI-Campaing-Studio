### 2.4. `spikes/renderer/COMPARISON.md` — 6-kriterijumsko poređenje

| criterion | R-A (Playwright) | R-B (SVG/Pillow) | winner |
|---|---|---|---|
| Determinism | high | high | R-B (no browser state) |

| Implementation (A14 dio 2) | trivial + binary to ship | SVG lib swap = one line | roughly equal |

**R-B wins 3/6 decisively**, ties 2, loses 1. Odlučujući faktor je
**packaging** — chromium binary je hard "no" za local-first desktop
app (plan section 42 eksplicitno motivacija).

## 7. Ključne dizajn odluke (za review fokus)

### 7.1. Zašto ne iPad/Playwright, ako je 15x sporiji

- **Packaging** je odlučujući: chromium binary je ~150 MB download
  za krajnjeg korisnika, kontra Pillow koji je već project
  dependency. Za **local-first desktop app** koja eksplicitno NE
  želi brovser (plan section 42), ovo je hard "no".
- R-B PNG-ovi su 7x manji (51 KB vs 377 KB) — ovo je output
  koji ide u kampanju (preko 5-10 post varijanti), ne samo debug
  output.
- A14 dio 2 produkcijski kod za R-B je trivijalan: `cairosvg.svg2png(url=template.svg)` umjesto Pillow koda. Template
  `template.svg` je produkcijski artefakt; Pillow `render.py` je
  throwaway.

### 7.2. R-A i dalje vrijedan (za A17+ scenarios)

R-A ostaje u repou kao referenca za buduće scenarije koji trebaju:
- bogat CSS (gradijenti, multi-column, hover states)
- interaktivni web preview (ne statički PNG)
- dizajner-ergonomski workflow (CSS edit → live preview)

Za Slice-1 deterministički 1080x1350 PNG export, R-B je pravi
alat. Ako se u budućnosti pojavi zahtjev za bogatim CSS preview-em,
R-A spike se može ponovo pokrenuti.

### 7.3. `pyproject.toml` izmjene (i F1 fix — vidi §9 ispod)

**Trenutno ispravan oblik** (poslije F1 fixa u §9):

```toml
[project.optional-dependencies]
dev = [
    ...,
    "httpx>=0.27",
]
# ACS-F1-032: throwaway renderer spike candidates. NOT a runtime
# dependency of the production app -- these exist only to make
# ``spikes/renderer/`` runnable. A14 dio 2 (production renderer) will
# pin only the winner in [project.dependencies] after the spike
# decision is recorded in ``artifacts/renderer_spike_result.json``.
renderer-spike = ["playwright>=1.60"]
```

`renderer-spike` je SIBLING KLJUČ unutar iste `[project.optional-dependencies]`
sekcije gdje živi i `dev = [...]`. Setuptools / pip očekuje svaki ključ u
tabeli da bude direktno lista stringova — ne ugniježdena pod-tabela.

**Stari (WRONG) oblik** (koji je koordinator uhvatio u review-u — vidi §9):

```toml
# NEISPRAVNO — ovo kreira ugniježdenu tabelu, ne sibling listu:
[project.optional-dependencies.renderer-spike]
playwright = ["playwright>=1.60"]
```

TOML parser to prihvata, ALI setuptools-ova metadata-validacija odbija
sa `ValueError: must be array`. `pip install -e .` (i sve varijante)
PADAJU dok god je ova greška u fajlu. Vidi §9 za F1 fix detalje i
verifikaciju.

`extend-exclude = ["spikes"]` (Ruff sekcija) je i dalje ispravan — throwaway
HTML/SVG kod u spike-u se ne lint-uje (inače bi generisao stotine E501).
Glavni `dependencies` niz u `pyproject.toml` NEDIRAN.

## 9. Fix runda (F1) — nevažeća TOML struktura u `pyproject.toml`

### Detekcija

Koordinator (Claude review) našao je **KRITIČAN BUG**: moja izmjena
`pyproject.toml` imala je `[project.optional-dependencies.renderer-spike]`
kao **ugniježđenu tabelu** umjesto kao sibling ključ unutar postojeće
`[project.optional-dependencies]` sekcije. TOML parser je prihvatio
strukturu, ALI setuptools-ova metadata-validacija odbija sa:

```
ValueError: invalid pyproject.toml config:
  `project.optional-dependencies.renderer-spike`.
configuration error:
  `project.optional-dependencies.renderer-spike` must be array
GIVEN VALUE:
    {
        "playwright": [
            "playwright>=1.60"
        ]
    }
```

`pip install -e .` (i sve varijante) padaju. Reprodukovano lokalno
prije fixa.

**Zašto `pytest`/`ruff`/`mypy` NISU uhvatili ovo**: dijeljeni `.venv`
je instaliran PRIJE moje izmjene. Sve tri alat-ke koriste POSTOJEĆI
`.pth` unos i ne re-triggeruju metadata-parsing. Lekcija: `pytest -q`
NIJE dovoljan gate za packaging metadata — treba eksplicitan
`pip install --dry-run` za sva 3 scenarija.

### Fix

Zamijenjena ugniježdena tabela sa sibling ključem unutar iste
`[project.optional-dependencies]` sekcije (vidi §7.3 gore za tačan
prije/poslije diff).

### Verifikacija poslije fixa (koju je koordinator eksplicitno tražio)

```text
$ python -c "import tomllib; d=tomllib.load(open('pyproject.toml','rb')); print(d['project']['optional-dependencies'])"
{'dev': ['pytest>=8.2', 'pytest-cov>=5.0', 'ruff>=0.5', 'mypy>=1.10', 'httpx>=0.27'],
 'renderer-spike': ['playwright>=1.60']}
```

`renderer-spike` je PRAVA lista stringova (ne dict unutar dict-a).

```text
$ python -m pip install --dry-run --no-deps -e .
...
Would install ai-campaign-studio-0.1.0
(no ValueError)

$ python -m pip install --dry-run --no-deps -e ".[dev]"
...
Would install ai-campaign-studio-0.1.0
(no ValueError)

$ python -m pip install --dry-run --no-deps -e ".[renderer-spike]"
...
Would install ai-campaign-studio-0.1.0
(no ValueError)
```

Sva tri `pip install --dry-run` scenarija prolaze metadata-validation
korak. Stvarni dependency resolution ne pokrećem jer `--dry-run` flag
zaustavlja instalaciju (nema mrežnog fetcha), ali metadata-validation
korak je jedini relevantan za ovaj fix.
