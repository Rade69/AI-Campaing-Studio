## Implementation summary

`_contains_word` dobija keyword-only parametar `allow_digit_adjacent: bool = False`:

```python
def _contains_word(text_folded, term, *, allow_digit_adjacent=False) -> bool:
    folded_term = term.casefold()
    starts_word = re.match(r"\w", folded_term) is not None
    ends_word = re.search(r"\w$", folded_term) is not None
    if not (starts_word and ends_word):
        return folded_term in text_folded
    if allow_digit_adjacent:
        # [^\W\d] = word char that is NOT a digit (letter/underscore).
        # Block only that before/after; a digit is allowed.
        pattern = rf"(?<![^\W\d]){re.escape(folded_term)}(?![^\W\d])"
        return re.search(pattern, text_folded) is not None
    return re.search(rf"\b{re.escape(folded_term)}\b", text_folded) is not None
```

Pozivni sajtovi:

- `lint_claim` (prohibited_terms): `_contains_word(text_folded, term)` —
  BEZ izmjene, default `False` (strogo `\b...\b`, jedinice/jedini i dalje rade).
- `_numeric_reason_code` (currency_symbols): `allow_digit_adjacent=True`.
- `_numeric_reason_code` (duration_units): `allow_digit_adjacent=True`.

Ključna razlika: `\b` ne razlikuje "3dana" (cifra — legitiman signal) od
"nedana" (slovo — false positive), jer su cifra i slovo OBA `\w`. Lookaround
`(?<![^\W\d])`/`(?![^\W\d])` blokira samo slovo/underscore, a dozvoljava cifru
— pa "30KM"/"3dana" matchuju (specific price/duration), dok "bambus"/"danas"/
"nedana" i dalje ne matchuju.
