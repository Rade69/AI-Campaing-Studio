## Implementation summary

1. **Bridge — `pick_and_preview_performance_csv(raw_payload=None)`**:
   - lokalni `import webview` unutar metode (isti obrazac kao
     `__main__._open_window`; `architecture_boundaries` test nezavisno
     prolazi — 18/18),
   - `webview.windows[0].create_file_dialog(webview.OPEN_DIALOG, ...)`
     (single-window app),
   - prazan rezultat dijaloga → `ok=True, cancelled=True` (NE greška),
   - `PreviewPerformanceMapping().execute(file_path)` → mapiran
     `PerformanceCsvPreviewResultUiModel`,
   - parsiranje neuspješno → `VALIDATION_ERROR` bez leak-a (loguje samo
     `type(exc).__name__`, vraća fiksnu poruku).
2. **Bridge — `confirm_performance_import(raw_payload)`**:
   - validacija dict + `file_path`/`campaign_id` str non-empty +
     `platform_code` str-or-None,
   - nepostojeća kampanja → `VALIDATION_ERROR`,
   - `ConfirmPerformanceImport(repo).execute(file_path, column_overrides=None,
     platform_code=...)` → `MatchPerformanceImportBatch(repo).execute(batch.id,
     CampaignId(campaign_id))` — **`column_overrides` eksplicitno `None`
     (nema remapping UI u v1)**,
   - `valid_count=batch.matched_count`, `invalid_count=batch.unmatched_count`
     (G3 dokumentovana privremena semantika), plus 4 match brojača.
   - Dva nova `_LIFECYCLE_ERROR_MAPPERS`/`_LIFECYCLE_ERROR_MESSAGES` ulaza +
     dedikovani `_preview_err`/`_confirm_err` (exact DTO shape).
3. **ui_models** — `PerformanceCsvColumnUiModel`, `PerformanceCsvInvalidSampleUiModel`,
   `PerformanceCsvPreviewResultUiModel`, `ConfirmPerformanceImportResultUiModel`
   (frozen, JSON-safe, bez secret polja; `file_path` je jedini path u odgovoru
   i namjerno).
4. **contracts** — `pick_and_preview_performance_csv` +
   `confirm_performance_import` potpisi na `PresentationFacade`.
5. **pregled_izvoz SSR** — "Uvezi CSV" (`data-action="import-performance-csv"`)
   + "Potvrdi uvoz" (`data-action="confirm-performance-import"`, hidden) +
   `data-perf-import-result` callout (hidden), sve unutar `data-perf-card`
   kartice.
6. **app.js** — `importPerformanceCsv`/`confirmPerformanceImport`/`renderImportPreview`
   u postojećem click-delegacijskom IIFE-u (click-triggered, NEMA
   pywebviewready lifecycle po kontraktu); `file_path` drži u lokalnoj
   `_pendingImportFile` (NE ponovo otvara dialog); `campaign_id` reuse iz
   `appCampaignId`; SAV CSV-porijeklo tekst (header, candidates, invalid
   errors) kroz `escapeImportHtml` (XSS).
