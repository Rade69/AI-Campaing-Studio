## Dizajn (ista disciplina kao OpenAIAdapter)

- **Structured output**: `response_mime_type="application/json"` +
  `response_json_schema=request.json_schema`, plus `system_instruction` i
  `contents=[Content(role="user", parts=[Part(text=...)])]`.
- **Bounded retry**: max 2 pokušaja, retry na `ServerError` (5xx) i
  `ClientError` code 429; svaki retry logovan (`logging.warning`).
- **Error mapping** (u domain `InfrastructureError`, nikad ključ/SDK tekst):
  `ClientError` 401/403 → `INVALID_API_KEY`, `ClientError` 429 → `RATE_LIMIT`,
  `ServerError` → `PROVIDER_ERROR`, ostalo → `PROVIDER_ERROR`.
- **DI seam**: `GoogleAdapter(api_key, model, client=None)`.
- **`test_connection()`**: `ClientError` 401/403 → `False`; ostalo → mapirano.
- **`discover_models()`**: `models.list()` → `ModelProfile(source=DISCOVERED,
  provider_code="GOOGLE")`.
