## Implementation summary

### 1. `domain/analytics/match_key.py` — `compute_analytics_match_key`

```python
def compute_analytics_match_key(
    content_piece_id: str,
    content_revision_id: str,
    platform_code: str,
    format_code: str,
) -> str:
    joined = "|".join((content_piece_id, content_revision_id, platform_code, format_code))
    return hashlib.sha256(joined.encode("utf-8")).hexdigest()[:_KEY_LENGTH]
```

`_KEY_LENGTH = 32` hexa (128 bita — dovoljno za realan broj postova, nije
bezbjednosni token). `"|"` separator onemogućava ambiguitet granica polja
(`"ab"+"c"` != `"a"+"bc"`). Čista funkcija, stdlib-only, bez tajni/PII (heš,
ne konkatenacija).
