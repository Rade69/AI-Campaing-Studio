## Fix (2 fajla, scope-minimalan)

### `pyproject.toml`

Premjesti `protego` iz `web-discovery` optional extra u
`[project.dependencies]`. Web discovery je dio S2 vertical slice-a
(Canonical Plan §6, S2-G3) — nije opt-in feature za korisnike koji
"ne žele web ingestion". `web-discovery` extra je zadržan za
korisnike koji žele tanju instalaciju, ali canonical default install
i CI sada povlače `protego` bezuslovno.

```toml
dependencies = [
    ...
    "requests>=2.31",
    # S2-G3: RFC 9309 robots.txt parser used by
    # ``infrastructure/web_ingestion/robots_reader.py``. Promoted from
    # the ``web-discovery`` optional extra to a hard dependency because
    # the canonical install must include web discovery (it is part of
    # the S2 vertical slice, not an opt-in feature); the ``web-discovery``
    # extra is kept for explicit opt-in by users who want a slimmer
    # install, but CI and the canonical default install pull protego
    # unconditionally. Fixes CI run failures (mypy
    # [import-not-found]) observed on runs 34443402816, 34444009075,
    # 34444031507, 34444224234 (S2-010/S2-011 post-merge push).
    "protego>=0.6.2",
]
```

### `http_fetcher.py`

Dodaj `# type: ignore[arg-type]` na `super().__init__(*args, **kwargs)`,
`# type: ignore[override]` na `def send`, i `# type: ignore[arg-type]`
na `super().send(request, **kwargs)`. Runtime ponašanje **netaknuto**:
`HTTPAdapter.__init__` zaista prihvata `*args/**kwargs` (pozicioni
`pool_connections`, `pool_maxsize`, `max_retries`); `HTTPAdapter.send`
zaista prihvata bilo koje keyword argumente. mypy ne može dokazati
bez type stub-a za `requests`.
