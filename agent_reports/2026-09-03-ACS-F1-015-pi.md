## Implementation summary

- `ProviderConfig` / `ModelSelection` frozen dataclass-e, `updated_at: datetime`.
- `ProviderConfigRepositoryPort` / `ModelSelectionRepositoryPort` oba `@runtime_checkable`
  Protocol-a, framework-neutral (samo stdlib importi).
- `SqliteProviderConfigRepository` + `SqliteModelSelectionRepository` (dvije klase u jednom
  fajlu, dosljedno postojecem stilu gdje svaki port ima svoj adapter).
- `save_*` su idempotentni upserti (`ON CONFLICT(<pk>) DO UPDATE`), `configured`/`validated`
  cuvani kao INTEGER `0`/`1` i rekonstruisani `bool(...)`.
- `get_*` vraca `None` za nepostojeci kljuc (nikad greska).
- `list_provider_configs` sortira po `provider_code` (deterministicki).
- `credential_ref` je plain string referenca; NIJEDAN import `ports/secrets.py` /
  `infrastructure/secrets/`, NIJEDAN API key literal.
