## Design decisions (dokumentovano)

- **Plain `str` for cross-package references** (`content_language_context`,
  `CampaignTarget.channel/platform_code/format_code`) to keep the domain free
  of the `localization`/`channels` packages (both `forbidden_paths`); callers
  map at the boundary. Mirrors ACS-F1-001's `BrandSnapshot.language/locale/
  script` choice.
- **`LayoutSpec` fields are typed enums** (acceptance requirement): added
  `ImagePosition`/`HeadlinePosition`/`HeadlineScale`/`Overlay`/`LogoPosition`/
  `CtaStyle` to `visual/enums.py`. `LayoutSpec.format` stays `str` (data-driven
  registry code, not an enum).
- **`CampaignVisualSystem.image_treatment/logo_rule/cta_rule` are plain `str`**
  for A3 (their enum taxonomy is not specified); documented in docstring, the
  A4 boundary schema will type them.
- **`ContentPiece` docstring documents the approved-content contract**: an
  `APPROVED` piece must not change silently; revision creates a new `Revision`
  and returns status to `NEEDS_REVIEW` (application-layer rule, not enforced
  inside the dataclass).
- `templates.py` — hardcoded `LEAD_GENERATION_V1`, not a resource file
  (single template, domain-level; documented).
- All collections `tuple` (with `__post_init__` list→tuple coercion, matching
  ACS-F1-001's `_coerce_to_tuple` lesson), all dataclasses `frozen=True`, all
  enums `StrEnum`, timestamps `datetime` (timezone-aware). Pydantic NOT used.
