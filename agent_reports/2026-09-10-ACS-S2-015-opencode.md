2. **`build_approved_fact_from_candidate(candidate, snapshot) -> ApprovedFact`**
   — čista funkcija (bez repo-a), u `domain/facts/policies.py`. Uvijek
   `version=1`, `status=APPROVED`, **fresh `logical_fact_id`** (nov logički

   SourceReference(source_type="web_ingestion", uri=snapshot.url,
   snapshot_id=str(candidate.snapshot_id), chunk_id=str(candidate.chunk_id)
   if candidate.chunk_id else None)` → G-WI-EVIDENCE.
3. **`ApproveFactCandidate.execute`**: `get_fact_candidate` → `None` →
   `EntityNotFound`; `assert_candidate_proposed` → `InvariantViolation` ako
   nije PROPOSED; `get_source_snapshot` → `None` → `EntityNotFound`; build;
   `replace(candidate, status=APPROVED)`; pa `with unit_of_work: save_fact +
   save_fact_candidate + commit` (ATOMSKI).

   status=REJECTED)`, samo `save_fact_candidate` — `ApprovedFact` se NIKAD ne
