## Implementation summary

Dodat helper i zamijenjene SVE tri plain-substring provjere word-boundary regexom
(isti obrazac kao `_COUNT_LINE_RE` iz ACS-F1-017 R2-BF-1):

```python
def _contains_word(text_folded: str, term: str) -> bool:
    return re.search(rf"\b{re.escape(term.casefold())}\b", text_folded) is not None
```

Zamijenjeno:

1. `lint_claim` (prohibited terms): `term.casefold() in text_folded` →
   `_contains_word(text_folded, term)`.
2. `_numeric_reason_code` (currency symbols): `symbol.casefold() in text_folded`
   → `_contains_word(text_folded, symbol)`.
3. `_numeric_reason_code` (duration units): `unit in text_folded` →
   `_contains_word(text_folded, unit)`.

Zašto `\b` + `re.escape`:

- `\b` je granica riječi, pa `"jedinice"` NE matchuje `"jedini"`, `"danas"` NE
  matchuje `"dan"`, `"bambus"` NE matchuje `"BAM"` (casefold `"bam"`).
- `re.escape` čuva termine sa regex-specijalnim karakterima (`"100%"`, `"€"`) kao
  literale.
- Multi-word termini (`"bez rizika"`, `"potpuno sigurno"`) i dalje rade: `\b`
  se primjenjuje na početak/kraj cijele fraze, a `re.escape` čuva unutrašnji
  razmak — `\bbez\ rizika\b` matchuje frazu kao cjelinu (eksplicitan test ispod).
- Python 3 `re` je Unicode-aware, pa non-ASCII BHS `\b` (npr. `"vodeći"` sa `ć`)
  radi ispravno (eksplicitan test ispod).

# Fix runda (2026-09-04) — BF-1: `\b€\b` nikad ne matchuje (regres)

**Nalaz (Claude):** moj prethodni fix je primijenio word-boundary na SVE termine,
uključujući čisto-simboličke. `€` nije `\w` karakter, pa `\b€\b` ne može da se
usidri (nema prelaza `\w`↔ne-`\w` oko simbola okruženog razmacima/punktuacijom) —
prava cijena sa € ("Cijena je 500€") više NIKAD ne dobija `unsupported-price`.
Simbol ne može biti "dio" veće alfanumeričke riječi, pa je plain substring za
simbol bio ispravan i dovoljan — word-boundary ovdje nije ni trebao.

**Dodatni regres koji sam otkrio (nije u brief-u):** isti problem pogađa i
prohibited termin `"100%"` (iz stvarnog `default_v1.yaml`) — završava se
non-`\w` (`%`), pa `\b100%\b` ne može da se usidri nakon `%`. Posljedica: tvrdnja
"Uštedite 100%" više nije bila PROHIBITED (padala je na `unsupported-percent`
umjesto da je zabranjena). Ovo je regres koji je MOJ ACS-F1-020 fix uveo (original
plain substring je ispravno flagovao `100%`), pa sam ga zatvorio u istoj rundi —
ista klasa, isti fajl, ne širenje scope-a.

## Fix

`_contains_word` sada primjenjuje word-boundary SAMO na termine čija OBA kraja
su `\w`; inače pada na plain substring:

```python
def _contains_word(text_folded: str, term: str) -> bool:
    folded_term = term.casefold()
    starts_word = re.match(r"\w", folded_term) is not None
    ends_word = re.search(r"\w$", folded_term) is not None
    if starts_word and ends_word:
        return re.search(rf"\b{re.escape(folded_term)}\b", text_folded) is not None
    return folded_term in text_folded
```

- `jedini`/`dan`/`BAM`/`bez rizika` → word-boundary (zaštita od substring false
  positive-a, već PASS).
- `€` (nema `\w`) → plain substring.
- `100%` (završava `%`) → plain substring.
