## 3. Ključne odluke

### 3.1. `ExportCampaign` interno komponira `RenderPost` — ne prima ga kao zavisnost

Contract: "`ExportCampaign` interno konstruiše `RenderPost` iz sirovih portova (`content_repo`, `campaign_repo`, `visual_repo`, `renderer`), isti obrazac kao `run_system_b.py`."

```python
def _render_one_piece(self, piece, visual_system_id, folder_name):
    # ...
    render_post = RenderPost(
        content_repo=self._content_repo,
        campaign_repo=self._campaign_repo,
        visual_repo=self._visual_repo,
        renderer=self._renderer,
    )
    result = render_post.execute(piece.id, visual_system_id, tmp_path)
```

Razlog: `run_system_b.py` (koji je referentni obrazac) interno konstruiše `GenerateCampaignPlan`/`ApproveCampaignPlan`/`GenerateSocialPost` iz sirovih portova, NE kao konstruktorske zavisnosti. `ExportCampaign` je "orchestrator of a small pipeline", ne "peer of the renderer".

Alternativa (koju sam odbacio): primiti `RenderPost` kao `__init__` parametar. To bi bilo ČISTO NETOČNO jer bi `ExportCampaign` tada izgledao kao "consumer of an already-wired collaborator", a zapravo je "step in a sequence that has to wire the collaborators itself".

### 3.2. Folder numeracija prati `CampaignItem.order`, NE repo redoslijed

Sortiranje se radi u `_order_pieces_by_plan(pieces, plan)`:
- `order_by_item_id: dict[str, int]` = mapa `CampaignItem.id` → `CampaignItem.order`
- `sorted(pieces, key=lambda p: order_by_item_id.get(str(p.campaign_item_id), fallback))`
- `fallback = max(order) + 1` — piece-evi bez pridruženog `CampaignItem`-a (npr. nakon re-plan flow) idu na KRAJ u stabilnom redu

Test: `test_folder_numbering_follows_plan_item_order_not_repo_order` — fake `_FakeContentRepo` vraća piece-ove u OBRNUTOM redoslijedu (piece za item-2 prvo), ali `plan.items` kaže item-1 je order=1. Export MORA proizvesti `content-01` za piece-1, NE za prvi piece iz repoa.

### 3.3. Skip logika hvata SPECIFIČAN `EntityNotFound`, NE generičan `Exception`

Contract: "Ako `RenderPost` baci `EntityNotFound` (nema `LayoutSpec` za taj piece) → uhvatiti SPECIFIČNO taj izuzetak... NE hvatati generičan `Exception`."

```python
try:
    result = render_post.execute(piece.id, visual_system_id, tmp_path)
except EntityNotFound:
    return None, str(piece.id)  # SPECIFIC skip: no LayoutSpec
```

Razlog: generičan `except Exception` bi sakrio STVARNE bug-ove (corrupt Pillow state, I/O error, schema bug). Samo `EntityNotFound` signalizira "piece was never put through `PlanPostLayout`, no layout spec exists" — legitimni skip razlog. Sve ostalo propagira.

### 3.4. Telemetrija NE izmišlja token/cost brojke

Contract: "Token/cost/latency metrike nisu dostupne — trenutno se ne perzistuju nigdje u sistemu (vidi Revision šemu)."

Provjereno: `Revision` entitet (`domain/content/revisions.py`) ima samo `provider`/`model`/`prompt_version`/`instruction` — NEMA `input_tokens`/`output_tokens`/`latency_ms` kolona. `Revision` SQL tabela ista. `GenerateSocialPost`/`ReviseContentPiece` perzistuju samo `provider`/`model`. `GenerateCampaignPlan`/`GenerateVisualSystem`/`PlanPostLayout` NE perzistuju NIŠTA telemetrijsko.

```python

```

Test: `test_telemetry_aggregates_provider_and_model` provjerava da `note.lower()` sadrži "nisu" + "token/cost/latency" + "nije propust" — eksplicitna deklaracija ograničenja, ne izmišljotina.

### 3.5. Temp PNG putanja preko `tempfile`, NE BytesIO

Contract: "<temp PNG putanja preko `tempfile`>".

`RenderPost.execute(input, vs_id, output_path)` zahtijeva `str` path na disku (NE BytesIO). Koristim `tempfile.NamedTemporaryFile(prefix="acs-export-", suffix=".png", delete=False)`. Čitam bajtove sa `Path(tmp_path).read_bytes()` poslije, brišem u `finally` (best-effort, ignorišem `OSError` jer Windows drži fajl kratko nakon close).

### 3.6. AR1 (Clean/Hexagonal) compliance: `export_campaign.py` NE importuje `infrastructure/export/`

`application/export/export_campaign.py` importuje SAMO:
- `ai_campaign_studio.application.rendering` (interni use-case)

- `ai_campaign_studio.ports.export` (Protocol + dataclass)
- `ai_campaign_studio.ports.rendering` (RendererPort)

## 9. Notes / lessons

1. **Default vs sentinel u test fake-ovima.** Kada `_Fake*Repo` klasa ima default `param = _default_fixture()` umjesto `param = None`, gubi se razlika između "no fixture" i "use default". Pattern: koristiti `MISSING = _Missing()` module-level sentinel, u fake klasi samo `self._x = x` (bez defaulta), a u `_use_case` helper-u raditi `effective = x if x is not MISSING else _default()`. Time test_missing_X može proslijediti `None` bez konflikta sa "no argument".
2. **`get_type_hints` lokacija u Python 3.14.** U Python 3.14 `inspect.get_type_hints` je uklonjen — sada je `typing.get_type_hints`. Lekcija iz ACS-F1-033/034 debugginga.
3. **SOLUTION role ne postoji u `CampaignRole` enum.** Vidim iz pydantic ValidationError: dozvoljeni su PROBLEM/EDUCATION/INSIGHT/BENEFIT/PROOF/TRUST/OBJECTION/MYTH_BUSTING/COMPARISON/BEHIND_THE_SCENES/PRODUCT/OFFER/URGENCY/ACTION/COMMUNITY/STORY/FAQ. SOLUTION nije među njima (preimenovan u EDUCATION ili nešto drugo). Za test sam koristio PROBLEM + EDUCATION.
4. **`_FakeCampaignRepo` parametrizacija sa None kao default test signal.** `_FakeCampaignRepo(campaign=None)` znači "no campaign" (test će failovati na `get_campaign`). Za happy path, `_use_case` MORA eksplicitno proslijediti default `_campaign()`.
5. **Stdlib `zipfile.ZipFile(mode="w")` je `ZIP_DEFLATED` po defaultu.** Ne treba eksplicitno `compression=ZIP_DEFLATED` ali sam ostavio u kodu kao dokumentaciju + zaštitu od budućeg "optimisation" PR-a koji bi prešao na STORED.
6. **Integration test "byte-stability" mora stripirati UUID/timestamp razlike.** Dva runa istog exporta imaju iste ključeve/tipove ali različite UUID-ove (`new_id()` svaki put generiše nov) i `created_at`/`exported_at` timestampove. Test poredi SCHEMA shape (ključevi + tipovi + duljine), ne vrijednosti.
7. **`PYTHONPATH` env var se NE prenosi kroz phase0 gate subprocess.** Ako test treba `src/` u sys.path, MORA biti u `pyproject.toml` `pythonpath = ["src"]` (lesson saved from ACS-F1-033). Svi ACS-F1-034 testovi rade jer je to već postavljeno u `pyproject.toml` od ACS-F1-033.

## 10. Preostali rizici

- **`new_id()` UUID-ovi u payload.** Export JSON sadrži `id`-eve (campaign, plan, visual_system, content_piece) kao UUID-ove. Ovo je dizajn — `campaign.json` je "machine-readable" i čita se sa strane. Ako budući korisnik želi "human-readable" export, dodati `id_human` polje ili alias mapu; trenutno NEMA potrebe.
- **Telemetrija nema `versioning` polja.** Ako `Revision` šema doda `input_tokens` u budućnosti, `telemetry/ai_summary.json` NEĆE to automatski pokupiti (ručno dodavanje u `export_campaign.py`). Ovo je namjerno — želimo eksplicitnu notu "nisu dostupne" dok god nisu, ne implicitno prazne liste.
- **Caption.txt je `piece.payload.caption.encode("utf-8")`.** Ako `caption` sadrži karaktere van BMP-a (npr. emoji 4-byte UTF-8), `ensure_ascii=False` će ih sačuvati. ALI, ako neki ZIP reader tumači kao CP437/Latin-1, dobit će garbage. Stdlib `zipfile` piše UTF-8 (CPython 3 default za `mode="w"`), tako da nema problema sa stdlib čitačem. Nepoznato za 3rd-party ZIP alate.
