Pravi tab-panel switching za Brend i Podešavanja (prethodno kozmetički
tab-ovi — klik je samo mijenjao `.active` klasu, sav sadržaj je bio
stalno vidljiv i stackovan). Plus content-language picker (SR/HR/BS/EN)
u Podešavanja → Jezik, po eksplicitnom zahtjevu Human Owner-a
(2026-09-03, locked order Srpski → Hrvatski → Bosanski → Engleski).

## Šta je urađeno

### Brend (`screens/brend/__init__.py`)
- `_tabs_row()` sada prima `panel_ids` i emituje
  `data-tab-target="<panel-id>"` na svakom tab label-u.
- `render_body()` razdvaja sadržaj u 4 top-level panela
  (`data-tab-panel id="panel-*"`), svi osim default-a nose `hidden`:
  - `panel-osnovni` (default, bez `hidden`) — brand info + glas brenda badge-ovi
  - `panel-cinjenice` (hidden) — odobrene činjenice
  - `panel-glas` (hidden) — placeholder callout (voice workspace tek dolazi)
  - `panel-resursi` (hidden) — brend resursi grid

### Podešavanja (`screens/podesavanja/__init__.py`)
- `_settings_tabs()` prelazi sa inline `style="display:block;..."` na
  `class="tabs tabs-vertical"` + emituje `data-tab-target` po tab-u.
- `render_body()` razdvaja desnu kolonu u 3 panela:
  - `panel-opste` (hidden) — placeholder callout
  - `panel-jezik` (hidden) — language picker (novi `_language_picker()`)
  - `panel-provajderi` (default) — 6 providera + production-tok callout
- Novi `LANGUAGES` tuple (SR/HR/BS/EN, locked order) i `DEFAULT_LANGUAGE = "SR"`.

### JS (`static/app.js`)
- `data-action="tab"` handler proširen: pored `.active` klase, sada
  sakriva/prikazuje panele preko `data-tab-target` → `data-tab-panel` id
  match (document-wide query — radi za Brend-ove horizontalne tabove i
  Podešavanja-ove vertikalne tabove u desnoj koloni).
- Novi `data-action="lang-pick"` handler: mijenja `.lang-active` i
  `✓` mark unutar `.lang-picker` grupe + pokazuje toast.

### CSS (`static/app.css`)
- Dodato: `.tabs-vertical`, `.tabs-vertical .tab`, `.lang-picker`,
  `.lang-row`, `.lang-row:hover`, `.lang-row.lang-active`,
  `.lang-row.lang-active:hover`, `.lang-row .lang-mark`,
  `.lang-row .lang-name`.

### Testovi
- `test_brend_ssr.py`: +4 testa — `data-tab-target` po tabu, panel id
  regex (tačno 4 panela, default bez `hidden`, ostali sa `hidden`),
  prvi tab default-active.
- `test_podesavanja_ssr.py`: +7 testova — `data-tab-target` po tabu,
  panel id regex (3 panela, AI provajderi default), `tabs-vertical`
  klasa (bez inline style-a), Opšte placeholder + Jezik picker,
  `LANGUAGES` locked order (SR/HR/BS/EN), 4 buttona u redoslijedu,
  `DEFAULT_LANGUAGE` pre-markiran active sa `✓`.
