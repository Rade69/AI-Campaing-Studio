# ROOT CAUSE I FIX

- BUILD_FACTS je birao targete samo po `snapshot_id`, pa je obrađivao i
  `FAILED` target čiji je stari snapshot ID SQLite namjerno zadržao. Sada bira
  isključivo `EXTRACTED` targete.
- Snapshot ID je bio samo `run_id + URL`. Recovery refetch sa drugim
  `content_hash` zato je prepisivao snapshot red, dok su chunkovi koji više ne
  postoje ostajali vezani za isti ID. Sada isti hash ponovo koristi postojeći
  ID (crash-idempotency), a promijenjen hash dobija deterministični
  content-version ID i zaseban provenance chain.
