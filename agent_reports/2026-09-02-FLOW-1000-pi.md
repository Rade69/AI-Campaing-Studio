## Implementation summary

Added one guard clause in `GenerateSocialPost.execute()`, immediately after the
`plan is None` check and before the `campaign_item` lookup (hence before any AI
call or persistence):

```python
if plan.status is not CampaignPlanStatus.APPROVED:
    raise InvariantViolation(
        f"campaign plan {plan_id} is {plan.status.value}; only an "
        "APPROVED plan can be used to generate posts"
    )
```

Added `CampaignPlanStatus` to the existing `domain.campaign.enums` import. The
public `execute()` signature is unchanged.
